## 催办作业口径 SOP（时段 / 频次 / 默认态）

本文件陈述催办的**产品默认硬约束**。以下三项的判定与阻断是 **os 侧（沟通网关催办策略）硬编码的产品默认值**，不可被 Pack、角色、模型或用户配置为更宽；**Pack 只做知识陈述，不做执行实现，也不是这些约束的真相源**。

### 一、发送时段

| 时段（客户所在地时间） | 判定 |
|---|---|
| 09:00–18:00 | 允许发送催办 |
| 22:00–08:00 | **硬禁**，任何情况不得发送 |
| 其余时段（08:00–09:00、18:00–22:00） | 不允许，返回 `blocked_out_of_working_hours` |

被时段阻断时，候选带 `policy_status=blocked` 与 `earliest_allowed_at`（下一个允许发送的时刻），**不自动改时间发送、不排队自动补发**；是否在允许时段重提由 Owner 决定。

### 二、频次上限

- 同一笔应收（按单据号标识）在 **7 日滚动窗内主动提醒不超过 2 次**。
- 触顶时返回 `blocked_frequency_cap`，并附近期提醒的回执引用作为证据。
- 频次证据源 = 既有沟通回执账本按单据号反查近 7 日已 dispatched 的催办回执；**不建平行计数真相**。
- 反查不可用（账本未接通、查询失败）时 **fail-closed** 为 `blocked_frequency_unknown`，不得按"查不到就当作 0 次"放行。
- 催办为 1:1 会话，不占用群发通道的月度条数计数器；候选携带 `channel_hint: "one_to_one"` 供通道层分流。

### 三、话术与禁用词

- 只允许中性事实性模板（见 `neutral-dunning-templates.md`），模板集随本 Pack 打包并在 os 侧做白名单校验；非白名单模板返回 `blocked_template_not_allowlisted`。
- 命中禁用词表（见 `forbidden-phrases.md`：威胁性措辞 / 暗示法律后果 / 涉第三人）时一票否决，返回 `vetoed_forbidden_phrase`，只产 blocked 候选并附命中词，**不产出可发送草稿**。

### 四、默认态与高级模式

- **本波不实现任何放宽开关**：没有"高级模式"、没有"紧急催办"、没有"Owner 一键跳过时段/频次"。默认态即全部能力。
- 任何未来的放宽方案属主权策略变更，须回 Owner 裁定并同步 os 侧策略与本 SOP，不得由 Pack 单方声明。

### 五、账龄事实口径（供催办优先级参考）

- 应收事实来源 = ERPNext Sales Invoice 只读快照（`docstatus=1`），Pack 不写回。
- 逾期识别：未收金额 > 0 且 `as_of` 晚于到期日，且单据状态不属于已付 / 已取消 / 退货 / 草稿。
- 到期日缺失时以过账日回退，并在行级显式标注 `due_basis=posting_date_fallback`；**不猜、不吞**。逾期基准日的最终口径待 Owner 裁定。
- 账龄分桶：未到期 / 1–30 / 31–60 / 61–90 / 91–120 / 120+ 天。
- 多币种不折算，按币种分组各自成行。
- 无任何 Sales Invoice 快照时诚实返回 `not_ready`，不得用 fixture、模板或估算冒充账龄事实。

### 六、主权纪律

1. 催办草稿永远只是 `CommunicationDraftCandidate`；被策略裁剪为 blocked 时仍是候选，不得包装成"已发送"或"已催办"。
2. 发送是高风险正式动作：须 Owner 五要素确认 + Base Gate 裁定（`decision_ref` / `run_id` / `nonce` 由 Base 签发），并产可在 03 反查的 Receipt；回执失败即动作失败。
3. 减免、延期、付款计划变更、单据写回、正式记忆入库同样须回 Owner + Base Gate，不可委托给角色 agent。
4. 本 SOP 的所有阈值若与 os 侧实现不一致，以 os 侧实现为准并回报修正本文件；知识陈述不得反向覆盖执行真相。
