# 权威资料投放区（Owner 放原始资料到这里）

本目录用于 Owner 在本机投放与应收催办相关的权威原始资料，例如：

- 公司自有的收款方式说明、对账与催办作业规范
- 合同中的付款条件、账期与违约条款范本（**不含真实签署件与真实客户信息**）
- 债权催收相关的合规要求、行业自律规范原文或官方链接清单

## 纪律

1. **原始资料一律不进 Git**：本目录除 `.gitignore` 与本 README 外的一切文件都被忽略。
2. **真实客户数据不得进入本仓任何位置**：真实客户名、单据号、金额、手机号、身份证号、银行账号等属业务数据与 PII，禁品扫描会拦截。
3. 整理进 `../knowledge/` 的内容必须**合成或脱敏**，逐条标注来源、kind、知识域与 `verification_status=pending_human_review`。
4. 催收合规为高风险领域：正式对外适用前必须经 Owner / 法务逐条核验，并以现行有效法律法规与合同原文为准。正式裁定权在 Owner + Base Gate。
